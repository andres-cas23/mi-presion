# Frontend de Mi Presión

Página web en HTML, CSS y JavaScript sin herramientas de compilación.
La explicación completa de cada carpeta está en `docs/03-estructura-frontend.md`.

Para verla en su computador (con el backend encendido):

```bash
cd frontend
python -m http.server 5500
```

Y abra http://127.0.0.1:5500
